What is VeDock?+

VeDock is a Windows desktop workspace for Cloudflare D1 databases, R2 storage, and Workers logs. It brings common development and maintenance tasks into one app.

Can I download it today?+

Not yet. VeDock is in development and has not been publicly released. The walkthroughs on this page illustrate the product with sample data.

Which operating systems is it for?+

VeDock is being built for Windows 10 and Windows 11 on x64. It is a desktop application, not a browser extension.

Do I need a Cloudflare account?+

Yes. VeDock works with resources in your own Cloudflare account. Cloudflare’s service availability, permissions, retention, and usage rules still apply.

How do I connect my account?+

You sign in through Cloudflare OAuth and choose the modules and access levels you need. You do not paste an API token into VeDock.

Where does VeDock store my information?+

Credentials, cache, query history, and job records are stored locally on your device. API requests go directly to Cloudflare. Viewed log events stay in memory; VeDock does not create a local log archive.

What happens before a change is written?+

Table edits are staged for review. R2 overwrites require an explicit choice, and deletion goes through scope, scan, preflight, and confirmation. An uncertain result is reconciled before retrying the write.

Does History use the same access as Live logs?+

No. History needs the separate Workers Observability permission that Cloudflare calls Write, even though the feature is used to view logs. Live logs uses its own permission. You choose what to authorize.
