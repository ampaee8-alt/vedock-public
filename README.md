# VeDock for Cloudflare®

VeDock is a Windows desktop app for developers who manage several Cloudflare accounts. It signs in with Cloudflare OAuth (no pasted API tokens), and gives you a safe place to work with D1 databases, R2 buckets and Workers logs: previews before every write, a journal for every destructive job, and confirmations that require you to type the number of objects you are about to delete. Everything stays on your machine; there is no VeDock backend.

This repository is the **public** side of the project. It will hold:

- Release notes and changelog
- Privacy policy and terms of use
- User guides and troubleshooting
- Issue tracker for bug reports and feature requests

The application source code is not published here.
